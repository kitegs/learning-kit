# 紧凑笔记与章节导航实现

- 日期：2026-09-01
- 状态：implemented

## 实现

- `NotesView` 的固定侧栏改为 42px rail / 200–460px panel 双态布局，状态和宽度存入本机界面偏好。
- 展开面板使用标签切换笔记树与当前笔记章节；笔记树复用 Element Plus 原过滤接口。
- `OpenNotebookEditor` 在加载、编辑和标题变化时输出结构化章节项，并暴露按标题 ID 定位方法。
- 章节导航复用纸页原有翻页、滚动与短暂高亮逻辑，不建立第二套位置系统。
- 保留纸页内部浮动目录，满足临时查看；快捷键“切换笔记目录”控制共享侧栏章节视图。
