# DEV-20260804-02 第一阶段可靠性技术方案

## 数据演进

向 `content_blocks` 追加 `anchor_key`、`source_hash`、`stale`；保留已有 ID，引用始终指向 ID。新增 `ai_tool_runs` 保存 AI 工具请求的参数、预览摘要、执行结果和状态。

笔记正文被改写时，将已有笔记来源块标为 `stale`，不删除引用。块创建时保存选区锚点和引用文本，导航后由笔记视图恢复选区。

## 安全与备份

仅主进程调用 Electron `safeStorage` 加密 `apiKey.*` 设置；保留对旧明文设置的读取兼容。数据库备份先强制持久化，再复制到用户选择的位置；恢复文件先由 sql.js 验证，成功后原子写回当前数据库。

## AI 审计

确认操作前创建 `pending` 记录；执行后写入 `applied` 或 `failed`、结果摘要和可用的回滚描述。工具中心读取最近记录，用户可判断 AI 做过什么。
