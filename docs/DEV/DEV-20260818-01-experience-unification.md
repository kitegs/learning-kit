# 技术方案

## 反馈链路

`NotesView` 在脏状态、写入开始、写入成功和异常时派发 `lk:app-status`；`App` 持有全局状态并传入 `Dock`。这样不增加 IPC，也能让状态栏在用户视线稳定位置反馈结果。

## 工具层级

双页编辑器保留翻页、目录、撤销/重做和缩放提示。选择、画笔、荧光笔、橡皮、图形、纸张移动与画笔参数进入“绘制”弹层；字体和纸张布局进入“版式”弹层。现有方法、测试标识和数据格式保持不变。

## 视觉一致性

全局样式补充语义化 token、明显焦点环和减少动态效果规则。Dock 与搜索组件以 token 替代局部灰色文案，所有新增文案使用中文。
