# DEV-20260802-01 多主题视觉系统方案

## 实现

- 扩展 `ThemeId` 联合类型，并复用既有 `theme` 设置的持久化路径，兼容未知旧值回退为深色。
- `Dock.vue` 的左侧面板以预览卡展示主题，卡片直接调用设置 store 更新主题。
- 在 `global.scss` 用 `html[data-theme]` 覆盖设计令牌，避免各业务页面各自维护主题判断。
- 纸质笔记本维持其纸页纹理，同时根据全局主题调整桌面和纸张色调，保证长期书写时的低刺激观感。

## 验证

- 全量类型检查、生产构建和桌面启动 smoke test。
- 手动从左侧切换主题，检查 Dock、主内容和双页笔记本可见同步变化；重启后检查主题仍被保留。
