# DEV-20260802-02 学习闭环 P0 技术方案

## 实现策略

- 复用 `search:all` 的 FTS + LIKE 双通道；解析 `#tag`，通过 tags 字段兜底匹配，前端只过滤展示范围而不重复请求。
- 复用既有 `links` 关系表作为回链索引：新增 `srs:fromSource`，不改变旧 `srs:fromNote` 签名。
- 纸质笔记以序列化的双页状态建立限制为 80 条的本地撤销栈，覆盖文字和画布更改；图形继续保存为既有画布图像，避免破坏已有笔记数据。
- SRS 统计以间隔、遗忘次数计算新卡/待巩固/已掌握；易错卡通过 `derived_from` 链接导航回原始学习资料。

## 边界

现有手写层是 PNG 快照，不具备逐笔画命中信息。因此本期只做可靠历史恢复和常用图形，未宣称套索级对象编辑或 OCR。
