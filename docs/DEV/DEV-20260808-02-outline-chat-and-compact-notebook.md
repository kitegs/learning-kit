# DEV-20260808-02 对话层级与紧凑笔记工具栏

## 对话数据

新增兼容 IPC `db:turn:reparent`，保留旧 `turnMove`。服务端用递归 CTE 取得整棵子树：更新子树所属对话、根轮次的 `parent_turn_id` 与章节，按目标轮次前/内/后计算排序；首次移动记录原对话、章节、排序和父轮次，以便恢复。迁移仅新增 `origin_parent_turn_id`。

## 对话交互

`ConversationTurn` 在上 25%、中间 50%、下 25% 显示三种放置区域。中间建立父子追问；前后保持同级。每轮递归显示并带大纲编号，拖拽父轮次会携带全部后代。

## 笔记交互

`NotesView` 将常驻控件缩为保存、撤销、标题、AI 等快捷命令；格式、插入、手写、引用和视图入口放入可收起的功能区选项卡。`OpenNotebookEditor` 仅保留页码、基础绘制、撤销和缩放，将版式/图形等收纳至弹出面板或右键菜单。
