# DEV-20260802-03 内容块图谱、历史和属性视图方案

## 数据模型

- `content_blocks` 保存来源类型、来源 ID、内容、锚点和元数据；通过现有 `links` 表形成双向引用。
- `note_versions` 在标题或正文变更前写入去重快照（自动快照最多每三分钟一次）；恢复历史版本前再次保存当前内容。
- `entity_attributes` 按实体和键值保存可扩展属性，供表格、看板、画廊共用。

## 实现

- 新增 `blocks:*`、`notes:version:*`、`attrs:*` IPC，并同步 preload 和渲染层声明。
- PDF 新划线在同一持久化事务路径内生成 `book_highlight` 内容块；块元数据记录图书 ID 和页码。
- 属性视图直接读取笔记与其属性，不复制笔记数据；布局只是同一资料集的不同展示方式。
- 文本编辑器撤销栈保存正文与选择范围，纸质笔记维持双页状态的撤销栈。
