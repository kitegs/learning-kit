# REQ-20260804-02 第一阶段：可靠引用、可控 AI 与数据保护

## 目标

让学习资料能可靠回到来源，让 AI 的写入操作可预览、可追溯，并保障本地资料与 API 密钥的安全。

## 范围

- 内容块增加稳定锚点、来源摘要和来源变更状态；可从搜索或引用定位回笔记选区。
- 全局搜索支持对象筛选、标签、排序分数和关键词定位信息。
- EPUB 划线保留 CFI，能够回到精确文本；PDF 继续使用页码和矩形位置。
- AI 工具执行写入本地审计记录，展示待确认与最近执行记录。
- API Key 使用 Electron 系统安全存储加密；提供本地数据库备份与恢复。

## 非目标

- 不在本阶段加入云同步、多人协作或后台自动执行 AI 操作。
- 不修改既有表字段定义，仅通过兼容迁移新增字段和表。

## 验收

- 内容块引用能回到对应笔记选区；来源变更后能看到需检查提示。
- EPUB 划线可回到选中位置。
- 所有已确认 AI 写入都有时间、参数、结果与状态记录。
- 数据库文件不保留可直接读取的 API Key；可创建和恢复本地备份。
