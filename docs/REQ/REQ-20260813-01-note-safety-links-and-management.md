# REQ-20260813-01 笔记安全、位置链接与管理效率

状态：已实现

## 目标

修复新建笔记报错和纸质笔记自动保存丢失，支持目录文字跳转到另一篇笔记的具体位置；补充笔记管理快捷键、纸张宽度设置，并提高护眼主题下对话树文字对比度。

## 验收

- 从顶部或笔记管理区新建笔记都能得到正确 ID 并立即打开。
- 编辑、粘贴、分页和退出时不会用 `pages:[]` 覆盖有效内容；关闭窗口会等待最后一次编辑保存并落盘，发现历史损坏数据时优先恢复最近有效版本。
- 目标位置可创建块级锚点，目录文字可右键链接，点击后跳到对应笔记、双页与具体位置。
- 设置中可以配置打开笔记管理、新建笔记目录和创建笔记链接的快捷键。
- 纸张宽度可调整，表格和代码不会撑破纸页；护眼主题下对话树使用清晰深色文字。
