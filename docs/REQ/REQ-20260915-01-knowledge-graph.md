# 范围

复用 knowledge_points，新增有向关系（前置、包含、应用、对比）与笔记来源。知识库增加图谱入口，支持搜索、缩放、节点详情、关系增改删及来源跳转。

用户明确选择一篇笔记后才发送提取请求；模型返回节点、关系和原文证据，预览不写库，确认后事务保存。笔记变更、删除、无效端点和伪造证据应拒绝保存。不将模型提取视为事实；用户负责语义审核。

主聊天增加默认关闭的图谱增强检索开关。按问题命中知识点，最多一跳扩展，附来源笔记和路径；沿用输入预算。不引入图数据库、向量模型、外部 CDN 或新 native 依赖，不宣称完整 GraphRAG。

验收：类型检查、构建、逻辑及隔离 Electron 回归；确认前零持久化、重复确认防护、软删除过滤、参数校验、重启恢复和检索开关。真实云端与开发模式手测未执行时明确标记。
