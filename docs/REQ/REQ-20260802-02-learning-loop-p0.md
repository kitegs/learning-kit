# REQ-20260802-02 学习闭环 P0：找回、手写与复习回链

## 目标

让学习资料从“写进去”变成“找得到、复习时能回到原文”。范围覆盖全局搜索、纸质笔记的可恢复操作，以及由笔记、电子书、对话创建的来源闪卡。

## 验收

- 全局搜索可按笔记、对话、阅读、复习对象筛选，并支持 `#标签` 查询笔记和卡片。
- 笔记能查看已有的引用、派生闪卡等关联；可跳转的关联直接回到来源。
- 纸质双页笔记支持多步撤销/重做，且提供直线、箭头、方框、圆形标注。
- 从笔记、对话、电子书选区创建的卡片保存来源； Review 中可以回到来源。
- Review 提供待巩固/已掌握计数和易错卡回链。

## 后续

逐笔画套索、任意笔迹对象移动/缩放以及离线手写 OCR/公式识别需要将现有 PNG 笔迹迁移为矢量笔画模型，列为下一阶段，不以伪实现替代。
