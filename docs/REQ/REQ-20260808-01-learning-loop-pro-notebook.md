# 第二、三阶段：学习闭环与专业笔记体验

## 目标

把已有的笔记、电子书、对话与闪卡从分散功能连接成可追溯的学习闭环，并把纸质笔记从“位图画板”升级为可编辑、可撤销的对象化画布。

## 范围

- 新建或由内容生成的卡片使用 FSRS 排程；历史 SM-2 卡片保持原有排程，不迁移、不丢失。
- 每张 FSRS 卡片保存独立调度状态；复习界面提供四种结果的下次间隔预览，统计新增正确率与薄弱卡片。
- 笔记、对话、划线仍通过现有 `links` 表回链到闪卡；复习面板能定位原始内容。
- 双页笔记的新笔迹以矢量对象保存，支持压感平滑、选择、拖动、复制、删除和操作级撤销/重做；旧 PNG 笔迹继续显示。
- 历史版本采用 `diff` 的中文分词差异显示，供用户在回滚前检查。

## 兼容与验收

- 只新增表，不变更既有列定义；旧笔记、旧卡片和旧版本均能打开。
- 使用 `perfect-freehand`（MIT）、`diff`（BSD-3-Clause）、`ts-fsrs`（MIT），均为纯 JavaScript/TypeScript 包。
- 新增卡片、笔迹和复习记录在重启后保留；旧卡不因启用 FSRS 而改变到期时间。
