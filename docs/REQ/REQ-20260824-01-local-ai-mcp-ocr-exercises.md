# 本机 AI 工具、MCP、离线 OCR 与习题集

## 目标

让 Learning Kit 的内置 AI 和外部 Codex 都能安全管理本机学习资料；将 PDF/EPUB 内容、笔记、划线、习题与闪卡组成可回到原文的学习闭环。

## 已确认的产品规则

1. 内置 AI 只能提出工具操作，用户在 AI 工具管理中心预览并确认后执行。
2. 外部 Codex 使用仅本机 `stdio` MCP。MCP Bridge 不直接读取数据库，必须经 Windows 本机命名管道调用运行中的 Electron 主进程；应用未运行时返回“请先打开 Learning Kit”。
3. 外部 Codex 可直接创建、追加、整理、生成题目、生成闪卡与添加书签；删除、覆盖整篇笔记、批量移动、导入/恢复和 API/安全设置修改必须在 Learning Kit 内确认。
4. 题目生成前由用户明确选择来源：整本书、章节/页码、已划线内容或某篇笔记。
5. 习题集独立于闪卡。单选、多选、判断、简答、填空题都必须保存答案、解析、难度、知识点标签和一条或多条直达原文链接。客观题自动判分；简答题由用户自评“掌握/部分掌握/不会”；错题可手动转闪卡。
6. OCR 首版为普通离线方案：用户手动点击“识别本页 / 识别选定页 / 识别章节”；结果先以可选、可编辑、可合并/拆分的文字块叠加在书页上，只有“确认写入本地文本层”后才可搜索、引用和出题。
7. OCR 首版优先中文通用文本；表格、公式和图片区域保留原始图片区域/文本块，不伪造结构化公式或表格。
8. PDF 保留原生目录；没有目录或目录不足时，可用已确认 OCR 文字层生成补充目录，且可编辑。

## 范围与验收

- 能在工具中心看到带影响范围、预览、确认状态和结果的内置 AI 操作。
- 能通过 stdio MCP 列出、读取、创建/追加笔记，查询图书和来源内容，创建题集/题目/闪卡/书签，且每次操作都有审计记录和可用的单对象撤销。
- 关闭应用后外部 MCP 不会写入数据；MCP stdout 不输出非协议日志。
- 题集、作答记录、错题状态、来源链接和 OCR 文本块在重启、备份、恢复后均保留。
- PDF 普通模式左键拖选跨行文字后显示选区工具栏并可保存透明荧光笔；手绘模式才接管画布指针。
- OCR 文本块可修改、合并、拆分、确认，确认后能被全局搜索命中并可生成带来源链接的题目。

## 非目标

- 不开放 HTTP MCP、云端 OCR、多人协作或自动覆盖用户笔记。
- 首版不承诺数学公式 OCR、表格结构重建、自动答简答题或跨设备同步。
