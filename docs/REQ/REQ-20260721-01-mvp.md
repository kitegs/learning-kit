# 学习助手桌面端 MVP

## 背景
按 `E:\learning kit\requirement.md` 启动 AI 学习助手项目。本期明确做 Windows 平台，按用户决策**Electron + Vue 3**，**SQLite（sql.js）持久化**。MVP 第一阶段先聚焦 AI 对话主线，随后再做电子书、笔记、思维导图、SRS。

## 范围

### 包含
- AI 流式对话主界面 + 多服务商切换 + 模型选择
- 对话分组折叠管理（目录树、拖拽、展开折叠状态持久化）
- 消息级 编辑 / 加笔记 / 删除 / 复制
- 设置面板：API Key、温度、自定义 baseUrl、系统提示词
- 图书馆：导入 PDF、阅读器、目录、书签、划线
- PDF 选段询问 AI、悬浮 AI 球、划线笔记、关联对话
- 笔记：Markdown 编辑 + 目录树 + 标签 + 导出 + 一键生成闪卡
- 思维导图：嵌套 markdown → markmap 渲染，多图管理
- SRS：牌组/卡片 CRUD、SM-2 调度、复习会话、统计面板（间隔分布 + 60 天热力图 + 连续天数）
- AI 学习进度总结（聚合本地数据让模型给复习建议）
- 学习方案生成对话框（按 teach-skill 的 zpd/storage/反幻觉哲学）

### 不包含（本期暂不做，按用户要求）
- 安卓端 / 跨平台移动
- 多端实时同步、加密同步
- EPUB 渲染 UI（协议层已通，UI 待补）
- 视觉划线高亮框（仅文字保存）

## 用户故事

作为单用户私人学习者，我希望：
1. 在一个 App 内一站式完成 对话学习 / 听课 / 复习 / 笔记整理
2. 把 AI 回答关联回我读的书与章节，方便复习
3. 把对话折叠进目录避免长列表找不到
4. 让 AI 基于本地进度给我下一步学习建议
5. 用 SRS 节奏辅助记忆

## 验收标准

1. [x] `npm run typecheck` 0 errors
2. [x] `npm run build` 成功产出 out/
3. [x] `npm run dev` 启动后窗口标题 = "Learning Kit"，控制台无 `Error occurred` / `Cannot read` / `Unhandled`
4. [x] 设置真实 API Key 后流式对话能收到回复，可中途停止
5. [x] 关闭重开 App 后对话/笔记/卡片/划线/设置均保留
6. [x] 5 个模式（对话/图书馆/笔记/思维导图/复习）均可进入且无报错
7. [x] 系统提示词按 `promt/system.txt` 覆盖
