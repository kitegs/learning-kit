提供标准 stdio MCP Server，经本机管道连接运行中的桌面应用。支持提交笔记、知识点和查询导入状态；所有导入先在工具中心预览，经用户确认保存，支持拒绝和已有安全撤销。默认关闭，可开启、关闭、轮换凭据并复制客户端配置。重复 requestKey 不重复创建，内容改变则拒绝。桥接进程不打开数据库、不访问用户文件，也不调用付费模型。

验收包括协议客户端发现和调用工具、鉴权、输入限制、预览/确认/拒绝、断线重连、关闭禁用、重启持久化。主进程、preload、env 仅新增 MCP IPC；db.ts 仅新增防重表，不修改已有列；不修改默认 prompt、CSP 和应用入口字段。
