# REQ-20260811-02 笔记排版流与画笔控制

## 目标

让纸质笔记能可靠粘贴公式、表格与大量文字；内容超过当前纸页时按实际排版自动续到后续纸页。缩放统一使用 Ctrl/Command 加滚轮，并提供笔迹颜色、粗细和荧光透明度控制。

## 验收

- 粘贴带 `$...$`、`\\(...\\)` 或常见 `名称=函数(参数)` 形式的公式时，笔记中可读地显示公式；粘贴表格保留表格结构。
- 长段文字、图片或表格不会越过纸页底部；超过可用高度的内容会流入右页和后续双页。
- 只有 Ctrl/Command + 滚轮会缩放笔记本视图；普通滚轮不再改变缩放。
- 可在纸质笔记内调整画笔/图形颜色、笔迹粗细和荧光笔透明度，设置随笔记保存。
