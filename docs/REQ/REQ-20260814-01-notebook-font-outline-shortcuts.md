# 笔记字体、页内目录、快捷键与截图粘贴

## 目标

- 纸质笔记支持切换楷体、宋体、微软雅黑、衬线和等宽字体，并提供 12–32px 字号。
- 从 H1/H2/H3 自动生成笔记内目录，显示所在页码，点击后跳转并高亮标题。
- 增加 F2 重命名、目录开关和 H1/H2/H3 快捷键，并允许在设置中修改。
- Windows 截图可以直接通过 Ctrl+V 粘贴到当前纸页，保存和重启后仍然存在。

## 验收

字体版式写入笔记 JSON 并兼容旧数据；目录锚点稳定；截图使用 data URL 随正文保存；UI 自动化覆盖上述操作和重启持久化。
