# 笔记锚点跨笔记持久化 UI 测试

为“创建锚点 → 另一篇笔记创建链接 → 点击跨笔记定位 → 退出应用 → 重新启动 → 再次定位”建立可重复运行的 Electron UI 自动化测试。

## 验收标准

- 操作真实界面、右键菜单、位置选择弹窗、内部路由和数据库 IPC，不使用业务测试后门。
- 每次使用独立临时 `userData`，不读取或修改用户正式数据，结束后自动清理。
- 第一次启动验证创建与定位，第二次启动验证正文、内容块、链接和定位仍然有效。
- 失败时输出步骤、渲染异常和局部业务状态；通过 `npm run test:ui:notebook-anchor` 一键运行。
