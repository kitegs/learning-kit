# 统一知识收集箱

## 目标

让用户能将 AI 对话内容沉淀为可管理的正式笔记，并在一个统一入口按状态、来源和标签查找自己的知识。

## 第一阶段范围

- 在 AI 消息上提供“保存到知识库”。
- 自动创建并复用根级“收集箱”目录；沉淀的笔记默认进入此目录。
- 保留消息到笔记的双向数据关联，且不改变已有数据库列定义。
- 提供知识库聚合页：全部、收集箱、我的笔记、AI 沉淀、收藏（预留）和标签筛选。

## 验收标准

1. AI 或用户消息能保存为笔记，应用重启后仍可在收集箱找到。
2. 保存后的笔记保留可读来源信息，关联表中存在 message → note 关系。
3. 知识库可按来源、收集箱与标签过滤，并能打开对应笔记。
4. 类型检查与生产构建均通过。
