# 范围

主聊天新增独立开关：本地请求诊断、Agent 流程与最大步骤数。保留原有工具提案开关和逐项确认。诊断记录总耗时、首次内容时间、状态/失败分类、服务商真实 token 用量；未提供用量不得用估算冒充。

Agent 第一版是单次模型生成后有界执行，不是自主循环：模型生成、工具预览、等待确认、执行、失败重新预览。成功步骤不重放，重试占用步骤预算，模型失败由用户重新发送。不自动重试模型或写工具，避免重复费用和重复写入。

# 验收

诊断可在界面查看、清空、重启后保留，关闭不新增记录；不持久化 Key、请求正文、回复正文或原始错误。工具确认前不写业务数据，重启恢复待确认和失败步骤，超过上限拒绝提案及重试；停止或窗口关闭不继续提案。

需要类型检查、全量回归、构建、隔离 Electron 模拟 SSE 与重启验证。真实云端和人工 smoke 单独列出，不以模拟测试冒充。
