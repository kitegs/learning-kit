# REQ-20260808-02 对话层级与紧凑笔记工具栏

## 目标

修复对话轮次拖动后不能形成父子追问关系的问题，并降低纸质笔记编辑时工具栏对阅读空间的占用。

## 范围

- 一轮对话固定为“用户消息 + AI 回复”，拖动整轮时同时携带其全部子追问。
- 拖放位置明确区分“之前、作为追问、之后”；作为追问时建立持久化的 `parent_turn_id` 层级。
- 支持拖入章节、跨对话移动、恢复原位置，并阻止把一轮拖进自己或自己的后代。
- 对话流以多级标题式编号和缩进展示，放置目标有即时视觉提示。
- 笔记改为 Word 式紧凑快捷栏与可收起选项卡面板；纸页保留更大的可编辑空间。

## 验收

- 拖一轮到另一轮中央，刷新或重启后仍显示为该轮的追问。
- 拖到顶部/底部可调整同级顺序；拖进章节后仍保持可展开的连续流。
- 工具栏默认不超过两行，更多格式/插入/绘制功能可在选项卡中打开。
