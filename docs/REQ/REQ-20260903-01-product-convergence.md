# 产品收敛版本

## 目标

把 Learning Kit 从“功能丰富的原型”收敛为可以稳定完成日常学习的本地 Beta。优先保证资料不会丢失、核心操作可预测、关闭重开后状态可恢复，再处理视觉一致性和扩展能力。

## 版本原则

- 冻结新增功能；只修复会影响笔记、阅读、对话整理和数据恢复的缺陷。
- 修根因，不在每个页面重复增加补丁。
- 不更换 sql.js，不引入原生依赖，不进行破坏性 schema 变更。
- 保持现有数据和 IPC 向后兼容；迁移只能追加。
- MCP、完整习题集、OCR 编辑文字层等未闭环功能保留为实验性，不作为本版本完成条件。

## P0 用户旅程

### 1. 笔记

用户可以新建笔记，粘贴包含长文本、标题、列表、公式、表格和图片的内容，继续输入或绘制，使用全选、撤销、重做和画布移动，并在关闭应用后恢复完整内容、版式、笔迹、目录和链接。

### 2. 电子书

用户可以打开 PDF，跳转页面，缩放而不丢阅读位置，拖选文本并添加透明荧光标记、批注或便签；切换模块或重启应用后，仍回到同一本书的对应页面和位置。

### 3. 对话整理

用户可以在测试模式下创建多轮对话，把完整的 user + AI 轮次拖入折叠组、调整标题层级或跨对话移动；重启后层级、顺序和关联保持不变。

### 4. 数据恢复

保存失败、数据库损坏或恢复失败时必须明确告知用户，不得静默显示空资料；用户可以从最近有效备份恢复，并看到当前保存状态。

## P1 体验统一

- 菜单和用户可见操作统一使用中文。
- 相同快捷键在笔记、阅读器和对话中行为一致，输入时不误触全局操作。
- 参数入口可被发现：工具栏保留高频操作，右键提供上下文操作，设置负责默认值。
- 空状态、加载、保存、失败和实验性状态采用统一反馈。
- 优先修复主题对比度和键盘焦点，不再新增主题。

## 非目标

- 云同步、多人协作、移动端和插件市场。
- 全面重写编辑器、PDF 引擎或数据库。
- 新增 AI 模型供应商或自动代理能力。
- 新增笔记模式、画笔种类、OCR 引擎或属性视图类型。
- 正式完成标准 MCP Server 和习题集全部能力；它们在核心链路稳定后单独恢复开发。

## 验收标准

- 混合内容笔记保存、关闭、重开后文字、公式、表格、图片和笔迹数量一致。
- 连续执行撤销/重做、全选、跨页编辑和画布移动，不出现内容消失或跳到错误页面。
- PDF 缩放前后的阅读锚点保持可见；高亮透明度、页码、便签和阅读进度可以持久化。
- 对话轮次拖入折叠组及跨对话移动后，关闭重开仍能恢复关系和顺序。
- 数据库保存采用可恢复流程；损坏时不静默创建空资料库覆盖用户判断。
- 默认测试命令覆盖核心纯逻辑和持久化回归；核心 UI 流程有可重复执行的自动化测试。
- `npm run typecheck:web`、`npm run typecheck:node`、`npm test`、`npm run build` 全部通过。
- 使用独立测试数据完成一次创建、编辑、关闭、重开和恢复 smoke test，控制台没有未处理异常。
- 发布候选连续三次完整验证通过，且没有未关闭的 P0 缺陷。

## 退出条件

满足全部验收标准后版本状态改为 `done`，解除功能冻结。未完成项目转入后续独立需求，不允许以隐藏入口或“用户自行规避”视为完成。
