# REQ-20260802-03 内容块、历史版本与属性视图

## 目标

独立实现可被引用和搜索的学习内容块，让笔记、PDF 划线与闪卡保留细粒度来源；同时提供安全的笔记历史回滚和资料属性视图。

## 验收

- 笔记选区或当前双页可创建内容块，任意笔记可引用块，搜索可返回内容块。
- PDF 新划线自动创建内容块；笔记引用和阅读侧栏可以通过块回到书页。
- 从笔记创建的闪卡绑定到来源块，Review 可经由块回到原始笔记或书籍。
- 笔记修改自动创建去重历史快照；用户可预览保存版本与当前版本并安全回滚。
- 属性视图至少提供笔记的表格、看板、画廊布局，并能编辑状态、优先级、截止日期等属性。

## 边界

本期内容块锚点以选区偏移、当前双页、PDF 页码/划线为主；富文本 DOM 级稳定锚点、手写笔画级锚点和逐字符差异属于后续精细化阶段。
