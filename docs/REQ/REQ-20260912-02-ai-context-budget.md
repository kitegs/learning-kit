# 需求

用户要求“做上下文预算和检索”，并询问前端质感、真实云端联调与知识点/Draw.io 工具映射。

本轮范围：可调整的估算输入预算，默认关闭的本地笔记关键词检索，以及设置分区和聊天来源反馈。保留当前问题与系统规则；超预算拒发，旧历史按完整轮次裁剪。检索最多四条未删除普通笔记摘录，每条最多 1200 字符，最多占输入预算四分之一。无命中不补造来源。预算不含模型输出。

跨笔记检索仅主聊天入口；笔记 AI 与学习统计维持既有发送开关，统一执行预算。后两者当前上下文超限时提示缩短，而非自动摘要。设置保存重启有效，取消恢复。

不包含：向量检索、整本书检索、全应用视觉改版、知识点/Draw.io 新工具映射、需要真实 API key 的云端验收。真实云端联调需实际服务商流式响应、停止和连接测试，模拟测试不能替代。
