# PROG-20260811

## 电子书返回与文本标记修复

- 已完成：返回图书馆会清除当前阅读器；关闭最后一个电子书标签会落到图书馆页，不再无响应。
- 已完成：PDF 保存完整选区的所有行矩形，独立叠加可点击的半透明文本高亮层；旧的单矩形数据仍可读取。
- 已完成：EPUB 根据已保存的 CFI 立即恢复正文高亮，删除、章节/版式切换后同步更新。
- 已完成：手绘荧光笔透明度降低，并明确提示用户先退出手绘模式再进行文本拖选。
- 验证：`npm run typecheck`、`npm run build` 通过；开发启动 smoke-test 待记录。

## 笔记排版流与画笔控制

- 已完成：纸质笔记截获粘贴内容；保留表格结构，支持 LaTex 分隔公式及常见等式（如 `Index=Hash(Key)(modTableSize)`）的可读公式渲染。
- 已完成：分页改按真实 DOM 排版高度测量；文本、图片、表格和字号都会驱动右页/后续双页生成，纸张行数会同步改变页高和横线。
- 已完成：缩放统一为 Ctrl/Command + 滚轮，普通滚轮不再缩放；画笔设置可调整颜色、线宽与荧光笔透明度，并随笔记保存。
- 验证：`npm run typecheck`、`npm run build`、`npm test`（22 项）通过；开发版 Electron 已启动并显示 `Learning Kit`。
