# 本轮实现

- 按用户选择，由代理实施升级，用户跟着逐段理解。
- 提取 AiRequestRegistry，以 WebContents.id 和请求 ID 隔离请求；同一归属的活跃 ID 不允许复用。
- 停止操作只发送取消信号，finally 按控制器身份释放记录；渲染进程销毁取消其全部请求，晚到回调不再向已销毁进程发消息。
- 保留现有 IPC 签名、提示词加载、对话自定义提示词、上下文预算与检索行为，没有新增数据库持久化内容。
- 给请求管理模块及接入处补充中文设计注释，解释生命周期与异步竞态，不改变运行逻辑。
- 保留此前知识图谱等未提交变更，本轮没有提交或推送 GitHub。

# 验收边界与下一步

真实云端流式调用、连接测试和人工开发模式 smoke 尚未验收。本轮请求记录只存在内存中，不产生需跨重启恢复的数据；已有业务持久化未因本轮改变。不将自动化模拟 SSE 等同于真实云端验收，不声明全项目完成。

教学阅读顺序：begin 注册 → abort 发送取消信号 → release 清理 → ai.ts 的 try/finally 接入；后续再按独立阶段扩展请求诊断和 Agent 能力。
