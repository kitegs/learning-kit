# AI 闪卡执行链与 Electron 验证

新增 create_flashcard 工具动作，在 env.d.ts 同步类型；普通 ACTION:card 不再误映射至错题工具。主进程增加普通闪卡和错题闪卡预览、参数校验、事务写入及撤销。没有新增 IPC、store 或 schema 表，preload 现有通用工具方法可继续使用。

错题必须存在错误作答记录，提案预览使用数据库题面答案；确认时检测来源是否改变。普通闪卡保留答案内的竖线。新卡复用 srs.ts 的 FSRS 状态初始化，未选牌组时使用 AI 闪卡牌组。撤销检查整行快照及复习记录并清理 card_scheduling，保留可复用牌组。

验证：npm test 全通过，新增 sql.js 运行时测试覆盖提案、确认、数据库导出重建、FSRS、重复确认、撤销、修改冲突和错题来源变化；npm run typecheck 全通过；npm run build 通过（现有 Sass/Rollup 警告）；Electron 临时资料库测试通过设置重启恢复、待确认闪卡重启恢复、界面确认、卡片重启持久化及撤销。测试未操作真实资料库或使用真实 Key。

仍待：习题集、思维导图、学习计划等工具执行器；真实服务商联网流式/停止/连接测试及 npm run dev 人工 smoke。整体需求保持进行中，未提交推送。
