2. **sql.js statement 缓存报 Statement closed** → 删 cache + 每次 free（BUG-02）
3. **sql.js 数组参数被强转对象** → 直接传数组（BUG-02 同时修）
4. **preload 输出 .mjs 但主进程引用 .js** → 修路径（BUG-03）
5. **el-tree @node-click 搬运签名报错** → vue-tsc 报 unresolved；改正 scopefetch
6. **Postgres-style `DEFAULT (datetime('now'))`** 在 sql.js 中支持（OPTIONS），无问题
