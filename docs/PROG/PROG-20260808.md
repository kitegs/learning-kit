# PROG-20260808

## 第二、三阶段：学习闭环与专业笔记体验

- 接入 `ts-fsrs`：新建、笔记制卡、对话制卡和内容块制卡使用 FSRS；历史 SM-2 卡片保持原排程。复习卡展示四种评分的下一次间隔，统计增加 30 天正确率和 FSRS 卡片数。
- 卡片仍保留来源回链；薄弱卡列表可回到笔记、对话、内容块或书籍。
- 接入 `perfect-freehand`：新双页笔迹存为压感矢量对象，支持选择、拖动、缩放、复制、删除和操作级撤销/重做；旧 PNG 笔迹作为兼容底图保留。
- 接入 `diff`：笔记历史改为中文词级差异预览，回滚前可检查新增、删除与未变片段。

## 验证

- `npm run typecheck`、`npm test`、`npm run build` 均通过。
- Electron 开发窗口以 `Learning Kit` 标题正常启动。

## 对话层级与紧凑笔记工具栏修复

- 新增兼容的 `db:turn:reparent`：整轮问答及其追问子树可移动到另一轮之前、之后或内部；内部放置会持久化为真正的父子追问关系。首次移动会记录原父级，右键“恢复原位置”可还原。
- 对话轮次增加多级编号和拖放提示：悬停目标上/中/下区域分别表示同级之前、作为追问、同级之后；拖入章节继续作为顶层收纳。
- 笔记区域改为 Word 式快捷栏、功能区选项卡和默认收起的扩展面板。双页笔记的高频工具保持在一行，版式、图形和对象操作收纳到弹出面板及更多菜单。
- `npm run typecheck`、`npm run build` 通过；Electron 开发窗口正常启动。
