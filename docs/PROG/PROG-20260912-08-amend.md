# 对话独立 Prompt

- 顶栏 Prompt 按钮显示当前模式。对话支持继承全局 / 专属 / 不追加自定义；旧对话默认继承。
- 四个可编辑模板：编程导师、阅读理解、英语陪练、写作润色；覆盖草稿前确认，取消不保存。
- chat store 复用 settings IPC，按对话 ID 持久化 JSON；无新表、新 IPC、新依赖，不访问实际用户数据文件。
- 主进程按本次捕获的 conversationId 解析配置，专属替换全局自定义部分，内置文件 Prompt 保留。preload/env 请求只新增可选字段，不改变既有方法。
- 笔记 AI 和复习分析仍继承全局，当前入口只针对主聊天对话。
- npm run typecheck、npm test、npm run build 通过；构建仍有既有 Sass API / Rollup 注释警告。
- tests/ai-runtime.cjs 验证 A/B 隔离、缺省继承、none、全局关闭时专属仍有效、损坏配置拒绝发请求，以及既有流式/停止。
- node tests/conversation-prompt.e2e.cjs 在隔离 Electron 验证模板、编辑、取消、模式切换、两个对话隔离和关闭重启持久化，通过且无 Runtime.exceptionThrown。
- 测试维护：旧静态断言绑定全局直接调用写法，已更新为解析后合成；Element Plus 将测试属性透传到 textarea，改用显式容器定位后 UI 测试通过。
- 未完成验收：真实云端流式与连接测试、npm run dev 人工 smoke。未 commit/push。
