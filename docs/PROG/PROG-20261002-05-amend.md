本轮实现：

- 撤销在原事务内同时检查快照和后续依赖。图谱来源/关系证据、链接、子条目、任何来源内容块保护创建和追加撤销；属性、历史版本额外保护新建笔记删除。失败不改变 applied 状态，不级联清理用户后来产生的资料。复查中发现的版本/属性孤儿另记 BUG-06。
- 新增 tool:center IPC、preload/env 类型同步，仅增不改已有 API。队列和历史先按状态过滤再各自分页（12 项），created_at/id 确定排序；返回必要字段，不回传操作快照/参数副本。数据库结构、系统 prompt、CSP、运行入口未改。
- 新增 Pinia tool-center store 管理查询、分页、确认、拒绝、撤销、错误与刷新。主进程保持事实来源，操作串行且 busy 防重复；事件合并 80ms 刷新，序号防旧结果覆盖。MCP store 事件/配置/刷新采用同一序号机制。
- 共享工具元信息供主进程确认策略、Agent 能力检查与界面标签复用；知识点标题规则复用于手动知识库、图谱与工具创建，图谱解析也用同一归一化函数。桥接与主进程输入校验均保留，确认时再次拒绝同名创建；历史重复条目不自动整理。
- MCP 创建/重试/查询返回紧凑操作标签摘要，不回传正文；本机确认仍有完整预览。最大合法正文/描述的回执测试小于 500 字符。
- 工具中心分待确认/执行历史页签，支持来源/状态筛选和分页、折叠全文、可见错误与执行反馈、撤销二次确认。所有来源默认不选中；只执行本页显式选择。暗/亮主题提示使用项目变量。
