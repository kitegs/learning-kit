## 本地改动

- 用 TypeScript AST 提取并执行工具纯函数，保持审批与撤销内容冲突断言；新增 LF/CRLF、多行函数体与不存在笔记的测试。
- `.gitattributes` 固定源码/配置为 LF，bat 为 CRLF；不批量重写旧文件或修改 Git 配置。
- `.node-version` 定义 Node 24 基线，package/lock/README 同步最低 Node 24；不升级 Electron 或业务依赖。
- 官方 v7 Actions 使用已核验的完整 commit SHA；保留只读权限、不保存 checkout 凭据；添加手动触发和过期运行取消。
- 保留 verify 所有检查；通过后并行运行笔记、AI、MCP 三组 UI job，单项失败不会取消另外两项。
- 新增关闭失败窗口前的截图/脱敏诊断与超时保护，CI 仅上传 test-results/ui，保存 7 天。AI/MCP 成功截图也改到测试目录，不再覆盖 README 演示图片；本轮被测试自动覆盖的原演示图片已恢复。
- 新增截图采集测试，检查截图字节、凭据脱敏、DevTools 断连/超时及窗口不存在的处理，不复制 profile/store/客户端配置。
