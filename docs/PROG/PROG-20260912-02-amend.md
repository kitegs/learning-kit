# AI 流式容错与工具预校验

- 新增 ai-stream.ts，按 SSE 事件组装，处理 UTF-8 跨块、CRLF、多行 data、未换行尾包、完成标记、模型长度限制及服务商错误；提前 EOF 报错并保留调用方已收到的正文。
- ai.ts 请求上限五分钟，区分超时和用户中止；finally 清理计时器。
- 未实现的工具在预览阶段拒绝，不创建待确认记录；失败反馈写入应用状态，工具中心从持久化记录恢复待确认操作（当前上限 300 项）。
- 修正默认 prompt 的本地存储/主动云端发送描述，依据 BIZ-20260912-02 留痕，ACTION 格式未变。
- 设置取消时回滚本轮未保存的 AI 开关和附加 prompt；其他历史设置项的保存语义未改。
- 自动化测试、主进程和渲染层类型检查及构建通过；新增运行时测试覆盖未实现工具拒绝、SSE 多行/尾包/错误/中断。

本轮没有实现习题集、错题闪卡、思维导图等缺失执行器，仅提前拒绝不可执行提案。工具能力注册表及通用闪卡错误映射仍待完善。真实 Key 联网流式验收和开发模式人工 smoke 尚未完成，不关闭整体需求。
