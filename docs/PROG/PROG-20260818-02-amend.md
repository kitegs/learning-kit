# 笔记位置链接自动识别与重复跳转修复

- 纸页粘贴纯 `app://note`、`app://block`、`app://book`、`app://conv` 或 `app://kp` 链接时自动生成可点击应用内链接。
- 粘贴 `[标题](app://...)` 和带 HTML 锚点的内容时保留其链接语义。
- 修复重复点击同一个位置链接时 Vue 合并相同导航参数、导致无法再次定位的问题。
- UI 自动化覆盖“粘贴 → 自动链接化 → 点击跳转 → 重启后仍跳转”。
