# 实现

- 知识库新增知识图谱入口：复用知识点，提供 SVG 关系图、搜索、缩放、类型筛选、节点编辑、关系增改删、来源原文和笔记跳转。
- 新表 graph_edges / graph_sources：仅新增 CREATE TABLE IF NOT EXISTS，不修改已有列；整库备份包含新表。
- 新增 IPC graph:list、graph:note、graph:node:save、graph:edge:save、graph:edge:remove、graph:preview、graph:apply、graph:discard，同步 preload/env。新 Pinia store 封装所有图谱读写和提取请求。
- 明确选择笔记并点击发送才提取，不发送其它笔记或对话历史。模型响应先严格 JSON 校验，原文证据核验，通过预览和确认令牌后事务保存。同名唯一节点复用但不覆盖描述。
- 预览只存内存，15 分钟到期，绑定窗口；来源/图谱改变、重复确认、歧义同名与无效端点拒绝；写入异常回滚。写入 schedulePersist。
- 独立默认关闭的 aiGraphRetrievalEnabled：仅主聊天，一跳双向邻接扩展（保持关系方向说明），来源去重，与普通检索共用最多 4 个片段和预算。当前只支持完整知识点标题命中；来源变更或软删除不发送。
- 原有知识点生成工具撤销增加图谱引用检查；节点列表计数同步；删除关系确认捕获版本。
- 无新依赖、CDN、向量数据库或默认 system prompt 改动；无 Git 提交/推送。
