# 产品收敛阶段 2：笔记核心稳定

## 完成

- 将目录标题与内容锚点统一为可重放的纸页定位状态；分页或模型同步重画当前双页后仍会恢复定位高亮。
- 定位高亮只保留在界面，不写入笔记正文；继续编辑、翻页或下一次定位时清除。
- 移除 `open()` 内重复触发的锚点跳转，改为在纸页组件就绪后由挂载或跳转请求各执行一次。
- 为笔记打开与笔记树刷新增加最新请求保护，旧异步结果不再覆盖用户刚打开的笔记或最新目录。
- 新建笔记改为先切换编辑器、再刷新笔记树，避免树项目先出现时输入仍写入上一份笔记。
- 画布拖动依赖 pointer capture 的 `pointerup` / `pointercancel` 收尾，并允许在双页容器空白处开始拖动，不再被边界事件立即取消。
- UI 测试失败信息补充当前标题、树标题、数据库笔记和目标锚点现场，后续回归可直接区分保存、导航与渲染问题。

## 验证

- `npm run typecheck`：通过。
- `npm test`：18 个集成测试、13 个 Markdown 测试及工具策略测试通过。
- `npm run build`：通过。
- 笔记 UI 流程最终连续三次通过，覆盖粘贴、分页、公式、表格、图片、全选、撤销、画布移动、目录、跨笔记锚点及关闭重开。
- 数据库恢复 UI 回归通过：损坏主库后从最近有效副本恢复，并保留异常文件。
- `npm run dev` smoke test：窗口标题为 `Learning Kit`，可正常启动。
