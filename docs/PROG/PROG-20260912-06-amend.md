# 本轮实现

- App 既有 <kp>/<drawio> 标签映射为 create_knowledge_point/create_diagram，沿用 AI 工具提案开关和确认中心。
- 复用 knowledge_points/diagrams 和工具事务，无 schema 或 IPC 方法签名变动；env ToolAction 新增类型，两种操作对 internal-ai/MCP/renderer 均不可无确认直接执行。
- 知识点默认 unseen，不把 AI 建议写成掌握状态；书籍/章节仅记录未核实来源文字，不自动关联。知识库新增知识点筛选页与标题/描述编辑，保留原始关联和其他字段。
- Draw.io 提案使用 saxes 6.0.0 校验单页未压缩 XML 子集，限制尺寸/节点数/层级、标签/属性/样式白名单、拒绝 DTD/PI/CDATA/外部资源/HTML，检查 ID 和父子循环/连线端点/geometry。现有间接依赖转为直接生产依赖，同时修正 lock 中 xmlchars 的生产依赖标记，无 native 包。
- 工具中心显示图表简化结构预览（最多 100 节点，不保证所有样式及嵌套坐标与编辑器一致）、完整 XML、节点与连线数；确认后在现有思维导图模块的 Draw.io 列表打开。不是自动替换已有图表。
- 完整行快照撤销；知识点已编辑/有子知识点/代码引用/links 或图表已改动时拒绝撤销。
