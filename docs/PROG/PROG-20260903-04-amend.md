# 产品收敛阶段 3：电子书核心稳定

## 完成

- 将页码、缩放与归一化页内锚点从 PDF 渲染完成状态中分离，按书籍 ID 持久化。
- 翻页立即保存目标页；缩放和滚动采用节流保存，并在模块切换与应用关闭前刷新。
- PDF 重新挂载时恢复上次缩放与阅读锚点；外部指定页码跳转仍从目标页顶部开始。
- 统一便签坐标和文字保存快照，修复拖动后输入覆盖坐标、快速切换或退出丢失末尾文字的问题。
- 重绘使用渲染世代与卸载保护，组件销毁过程不再把预期取消上报成用户错误。
- 图书卡片、当前页、阅读画布和批注层补充稳定测试标识。
- 新增 `test:ui:pdf-reader`，使用临时 PDF 和隔离资料库验证真实 Electron 用户旅程。

## 验证

- PDF UI 流程连续三次通过：翻页、Ctrl+滚轮缩放、缩放锚点、文本标记、透明手绘荧光笔、便签拖动和输入、模块切换恢复、关闭重启恢复。
- 测试确认页码、缩放、页内位置、文本标记、手绘批注和便签均保持。

## 下一步

进入阶段 4，稳定完整对话轮次的折叠、标题层级、跨对话移动，并统一中文文案、快捷键和主题对比度。
