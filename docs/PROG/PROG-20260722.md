# 2026-07-22 进度

## 完成

### Bug 修复
- **流式显示不更新**：`assistantMsg` 是普通对象，push 进 ref 数组后回调里改原始对象不触发 Vue 响应式。修复：push 后从数组取 proxy 引用（`rMsg = activeMessages[last]`），之后所有修改走 `rMsg`。commit `75433ed`
- **msgSave 报 Wrong API use**：IPC handler 读 `m.conversationId`（驼峰）但调用方传 `conversation_id`（下划线），导致 undefined 绑定到 sql.js。修复：handler 改用 `m.conversation_id || m.conversationId`。commit `3fb5747`
- **Dock 布局遮挡内容**：dock-left 用 `position: absolute` 不占布局空间。修复：改用 CSS Grid 3 列布局，Dock 通过 slot 包裹内容。commit `e860483`
- **笔记布局溢出**：textare 高度 100% 解析为 100vh 溢出。修复：加 view-slot wrapper + flex 约束 + min-height:0 + overflow:hidden。commit `19249b3`
- **保存按钮不可点**：`@input="markDirty; onInputCheck()"` 中 `markDirty` 没加 `()`，Vue 多语句不会自动调用。commit `20b122c`
