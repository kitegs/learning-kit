# 2026-07-21 session-2 progress

- LeftRail added theme toggle button (Sunny/Moon icons)

### 2. Global search (Ctrl+K)
- New IPC `search:all` in electron/main/search.ts
- Full-text LIKE query across conversations, messages, notes, mindmaps, highlights, cards, books
- SearchOverlay + SearchSection components
- Ctrl+K shortcut registered in App.vue
- Jump to result: switches mode and opens conversation/book/note/highlight

### 3. Context menus (all views)
Created unified context menu system:
- Context menu store (`src/stores/context-menu.ts`) with `open(x, y, items)`
- ContextOverlay component renders overlay + menu
- MessageItem: edit / note / copy / reuse / make-card / delete
- SidebarView: open / rename / new-subgroup / new-conv / delete
- LibraryView: open / rename / delete
- PdfReaderView: existing selection popup + floating AI ball
- NotesView: tree nodes (open/rename/new-child/make-card/export/delete), editor (save/H1/H2/code/list/make-card/export)
- MindmapView: save / new / delete
- ReviewView: deck (select/rename/new-card/delete), card (edit/reset-progress/delete)

### 4. EPUB reader (epubjs)
- New EpubReaderView.vue using epubjs@0.3
- Loads via book:// protocol
- Side panel: TOC + bookmarks + highlights
- Page navigation (prev/next) via rendition
- Selection popup (parse/summary/save-highlight)
- Floating AI ball
- ContentComponent in App.vue picks PdfReaderView or EpubReaderView based on book.kind
- Bookmarks schema extended with href column for epub CFI locations

### 5. PDF visual highlight rects
- Schema migration for highlights: added rect_x, rect_y, rect_w, rect_h (REAL)
- saveSel computes normalized rect from window.getSelection().getClientRects()
- renderHighlights() adds colored div overlays on the pdf page element
- Clicking a highlight rect shows its text/note in a message popup

### 6. Notes richer toolbar + slash command
- Toolbar: H1/H2/H3 list quote code B I S link table + make-card + export + save
- Slash command: typing "/" opens a popup with markdown commands (headers, lists, quote, code, bold, italic, links, tables)
- Selecting a slash item replaces "/" with the appropriate markdown prefix

### 7. Bookmarks schema extension
- Added href TEXT column to bookmarks table
- IPC: bookmarkAdd now accepts optional href parameter
- Migration: ALTER TABLE ADD COLUMN href TEXT
