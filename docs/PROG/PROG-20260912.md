# AI 配置补齐与中断后复查

## 已实施

- 四个上下文/工具开关接入聊天、笔记 AI、学习建议；学习统计关闭时不启动个性化分析。
- 自定义附加提示词持久化，三个入口一致传入主进程，设置提供恢复默认按钮。
- 聊天停止、离开模块、卸载时中止请求并保存部分回答；笔记面板及学习建议关闭时中止请求。
- 正常完成清理监听，聊天准备期间加锁并用请求代次防止停止后的延迟启动。
- 修复 API Key 重载时 provider 前多出点号；修复温度 0 重载变成 0.6。
- 笔记 AI 与学习建议遵守本地测试模式。
- AI 请求/事件类型收紧，字段仅增加 customSystemPrompt，IPC 名称、参数位置、返回类型及旧方法保留。修改 preload/env 声明是为了补充请求字段并检查现有调用方。

## 验证

- npm test：18 个集成用例、13 个 Markdown 用例、工具策略、AI 契约及 AI 运行时测试通过。
- npm run typecheck：主进程及渲染层通过。
- npm run build：通过；已有 Sass legacy API / Rollup 注释警告。
- node tests/ai-settings.e2e.cjs：独立临时资料库启动真实 Electron，通过界面切换四个开关、编辑提示词、保存、关闭及重启恢复验证，无 Runtime.exceptionThrown。
- AI 运行时模拟测试覆盖文件 prompt 优先级、附加 prompt 启停、流式返回、中止信号和配置往返；未使用真实 API Key。
- git diff --check 通过。

## 未完成及复查发现

- 尚未做 npm run dev 人工 smoke、真实云端流式/停止/连接测试，因此 REQ/DEV/BUG 保持未关闭状态。
- 工具执行器尚不支持所有 prompt 声明的动作；习题集/错题闪卡确认仍会失败，思维导图/对话/计划等动作仍缺映射。下一批优先统一能力注册与执行器。
- 默认文件 prompt 仍有“全部数据留本地”的旧表述；本次设置页已解释实际发送行为，文件修改需补充决策及契约同步。
- SSE 尾包、超时、错误分类，分支上下文/token 预算，本地检索和模型能力适配均未纳入本批。
- 自定义 prompt 当前为附加模式，不是完整替换；提示词文字不是权限隔离，实际写入仍依赖主进程确认流程。
- aiIncludeNoteContext 控制笔记 AI 面板自动附带的正文；用户手动引用选段和历史中既有引用不受该开关追溯删除，设置已有说明。
- 设置表单仍直接绑定 store，取消关闭不会回滚未保存的内存配置；跨入口准备阶段的取消与重新打开竞态仍值得进一步覆盖。
