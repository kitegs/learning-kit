# 2026-07-21 session-3

## Completed

### Bug Fixes
- Ebook reader: Loading overlay was covering the full viewport because `.canvas-wrap` lacked `position:relative`; fixed to contain it only to the canvas area
- Sidebar disappearing after TOC click: `scrollIntoView` was scrolling the entire reader-root, hiding the sidebar. Replaced with manual `wrap.scrollTo` calculation
- Ctrl+wheel triggering both zoom AND native scroll: Vue `@wheel` template events are passive by default, making `preventDefault()` a no-op. Changed to `addEventListener('wheel', fn, { passive: false })` on window level, scoped to reader container
- Electron built-in Ctrl+wheel pinch zoom still fired: added `setVisualZoomLevelLimits(1,1)` in main process + `before-input-event` to swallow Ctrl+/=/-/0

### Ebook Reader Rewrite (single-page novel-style flip)
- Replaced the sluggish "render all pages in scroll" with single-page rendering
- Wheel = flip to next/prev page
- When page is zoomed in and scrollable, scroll first, then flip at edges
- Click left 35% / right 65% to flip pages
- Keyboard arrows = flip pages
- Mouse drag-to-flip: drag horizontally >60px to flip, with on-screen hint indicator
- Fit button (zoom=100%) and Reset button (page 1 + zoom=100% + scroll top)

### Keyboard Shortcuts
- Settings panel now has a full shortcuts editor with presets
- Default: Ctrl+K=Search, Ctrl+N=NewConv, Ctrl+L=Theme, Ctrl+Enter=Send, Ctrl+S=SaveNote, ArrowLeft/Right=PageFlip
- All shortcuts loaded/saved to DB, reset-to-default button in settings
- `matchShortcut(e, sc)` parser handles Ctrl/Shift/Alt modifiers correctly

### Sticky Notes on PDF Pages
- Added 'Sticky' tool to annotation toolbar
- Click anywhere on the annotation canvas to place a draggable sticky note
- Each note has a title bar (drag handle) with delete button
- Textarea auto-saves on change
- Notes persist across page switches and app restarts via `page_annotations` table (type: 'sticky')
- Each sticky stores: x, y, width, height, text, and color in JSON data field
- Right-click to delete

### Data Layer
- `page_annotations` table for per-page drawings, shapes, and sticky notes
- `annListAll` bulk-load IPC to avoid per-page loops
- `bookmarks` table extended with href column for EPUB support
- `highlights` table extended with rect_x/y/w/h columns for visual highlight overlays

## Issues Found and Fixed
| Issue | Root Cause | Fix |
|---|---|---|
| Ebook buttons unclickable | `.loading` div's absolute positioning leaked to viewport | Added `position:relative` to `.canvas-wrap` |
| Sidebar disappears on TOC jump | `scrollIntoView` causing parent scroll | Manual `scrollTo` calculation |
| Ctrl+wheel double-trigger | Passive event listener ignores preventDefault | Non-passive listener + main process zoom lock |
| renderAll performance freeze | O(n) IPC calls per page render | Single `annListAll` call + debounced rendering |
| Preload path .js not found | electron-vite outputs .mjs | Fixed to `.mjs` path |
| SQL Statement closed | sql.js statement re-use | No caching; prepare/free per call |
