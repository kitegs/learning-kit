## 实现

- 官方 SDK stdio Server，工具为 learning_kit_status/import_note/import_knowledge_point/import_status；工厂式入口兼容旧 initialize 握手与新版本协商，stdout 仅协议。独立 TypeScript 构建，不改 Electron main/type/bundle 入口。
- Windows named pipe + 256 位随机凭据；默认关闭，开关与轮换立即生效，轮换撤销旧配置。桥接无数据库/任意文件访问能力，不开放 HTTP 端口，也不调用付费模型；同用户恶意进程或管理员不在隔离范围内，不宣称 SID ACL。
- 重用 tool-service 的确认、审计、事务与安全撤销；所有 MCP 写入必须确认。新增 mcp_import_requests 表持久化 key/digest/operationId，提案与防重记录原子提交；相同 key/内容返回最新状态，内容变化拒绝，不重放 rejected/undone。
- 输入重复校验：标题 300 字、正文 30000 字、知识描述 10000 字；队列 100 项、单报文 256 KiB、最多 16 连接、10 秒超时、鉴权后每分钟 120 次请求。不提供自动确认、覆盖、删除、SQL 或文件工具。
- 新 IPC mcp:status/configure/client-config 与 mcp:changed 事件，preload/env 同步新增；新增 useMcpStore 和设置页组件。工具中心同时展示内部 AI 与外部 MCP，外部提案默认不勾选、全文预览；底栏保留待确认数量。
- 应用安全关闭先停止外部入口再持久化；保存失败取消关闭时保持进口暂停，允许用户处理保存问题后重新开关恢复。
- README 新增使用步骤、工具示例、防重、权限及成本说明；关键代码补中文注释。
