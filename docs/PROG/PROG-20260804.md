# PROG-20260804

## 完成

- 纸质双页笔记支持输入/粘贴大段文字后的自动续页。
- 工具栏增加字号、每页行数、每行字数，且每篇笔记分别持久化。
- 横线、正文行高和字号随版式设置同步变化；旧版纸质笔记自动采用默认版式。

## 验证

- `npm run typecheck`、`npm run build` 通过。
- 开发窗口以 `Learning Kit` 标题正常启动。

## 第一阶段：可靠引用、可控 AI 与数据保护

- 内容块新增稳定锚点、来源摘要和陈旧状态；笔记更新后引用保留并提示核对，可回到文本选区或纸质笔记所在双页。
- 全局搜索支持 `type:note`、`type:book`、`type:block` 等对象过滤，并在各对象内优先返回标题和正文更匹配的结果。
- EPUB 划线保存 CFI，搜索或侧栏回到划线时可恢复到对应文本位置；PDF 继续使用页码与矩形坐标。
- AI 工具中心记录待确认、完成、失败和忽略的本地操作审计；不改变既有确认机制。
- API Key 通过 Electron 系统安全存储加密；设置中可创建和恢复数据库备份，恢复前自动保留安全副本。
- 修复旧数据库迁移时索引先于新增列创建导致无法启动的问题。
