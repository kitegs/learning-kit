# AI 提示词分层与上下文授权策略

内置系统提示词继续由项目文件维护，承载隐私说明、结构化输出契约和工具确认边界；用户只能配置追加指令，不能替换内置安全规则。附加指令默认关闭。

对话历史默认开启，笔记上下文默认开启，学习统计默认开启，AI 工具提案默认开启。每项均可独立关闭；关闭后对应本地内容不得进入模型请求。设置页必须说明，主动调用云端 AI 时，启用的上下文会发送给所选服务商。
