补充并替代旧方案中 MCP 低风险操作可直接写入的策略：所有 MCP 写入均进入用户确认流程。此版仅提供新建笔记和知识点，不提供删除、覆盖、确认、任意 SQL、文件读取或开放网络接口。

Windows named pipe + 随机能力凭据保护连接。凭据保存在应用 settings 中，由用户主动复制到外部客户端环境变量；配置含密钥，不可公开。这里不宣称实现 Windows SID 专属 ACL，也无法阻止同用户恶意进程/管理员读取凭据；人工确认是第二道边界。关闭服务立即拒绝新请求并断开连接，已有待确认项保留。轮换凭据使旧配置失效。应用关闭时先停止入口，再持久化。

使用官方 TypeScript SDK 的稳定 v2 分包；不引入 Java/Python 服务或原生构建依赖。此功能免费本地运行，外部 AI 自身的模型消耗按其服务计费。
