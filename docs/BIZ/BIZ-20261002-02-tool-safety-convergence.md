type: BIZ
title: 撤销引用保护与知识点同名策略
created: 2026-10-02
status: accepted
relates: [REQ-20261002-03]
---

笔记存在图谱来源/关系、资料链接、子笔记或定位锚点时拒绝破坏性撤销，不级联删除后来产生的数据。追加笔记撤销同样保守保护引用，用户可先解除引用后重试。失败不改变已执行记录，保留撤销入口。

新知识点标题按 trim + Unicode 小写比较，仅针对未删除节点去重。不自动合并同名条目；预览和确认时均校验，防止两份待确认提案同时通过。图谱提取明确预览过的节点复用保持不变，历史重复条目不自动清理。

MCP 创建/重试/状态查询保留 operationId、status、affected、error、preview 字段，preview 改为操作标签摘要，不回传正文。实际正文仍保存在本地提案中供人工确认；不改外部确认权限。
