# 学习产物工具参数与兼容策略

补齐思维导图、学习计划、新对话和习题集创建及撤销。保持现有 ACTION 格式和 IPC；新增 exercise_set XML 标签承载 JSON 题目列表，旧 ACTION:exercise_set 仅有来源范围时明确拒绝，不创建空习题集。修改默认提示词的习题集输出契约以匹配实际必需数据，其他旧格式保留。

产物通过现有表写入，确认前不创建业务数据。撤销比较完整快照；习题新增、修改或已经作答、对话已有消息、产物已有链接时阻止撤销。计划和导图严格校验必需字段。新增动作同步 env.d.ts，无新增 IPC 或 schema。
