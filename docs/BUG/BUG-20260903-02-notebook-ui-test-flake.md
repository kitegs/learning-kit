# 问题

完整笔记锚点 UI 测试连续运行时，可能分别停在“章节目录定位标题”或“锚点已找到但高亮 class 尚未出现”。数据库保存和内容本身存在，失败点属于定位完成信号与页面重排之间的竞态。

## 当前处理

- 数据库损坏恢复改用同一 Electron/CDP 基础设施中的独立最小流程，不依赖这条不稳定的长测试。
- 保留原测试失败，不通过无限重跑把偶发通过当成稳定。

## 后续

在产品收敛阶段 2 统一笔记重排与定位完成信号，并把长测试拆为互不依赖的笔记核心流程。
