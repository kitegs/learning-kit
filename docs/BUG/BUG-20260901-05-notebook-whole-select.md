# Ctrl+A 只能选择当前纸页

- 日期：2026-09-01
- 状态：fixed
- 范围：`OpenNotebookEditor.vue`、`notebook-anchor.e2e.cjs`

## 原因

双页笔记把每张纸实现为独立的 `contenteditable`，并且只挂载当前双页。浏览器原生选区不能跨越多个编辑宿主，更无法选择尚未挂载的后续纸页，因此 `Ctrl+A` 只能处理光标所在的一页。

## 修复

- `Ctrl+A` 改为整本笔记的逻辑选区，工具栏和纸面会明确显示“已全选整本”。
- `Ctrl+C` / `Ctrl+X` 同时写入整本笔记的纯文本和富 HTML，并保留页码边界。
- `Delete` / `Backspace`、剪切以及全选后粘贴按整本处理；清空可使用 `Ctrl+Z` 恢复。
- `Esc` 或点击纸页取消整本选区；右键和更多菜单均提供“全选整本笔记”。
- Electron UI 测试验证跨页剪贴板内容包含第 1 页、第 2 页及原笔记正文。
