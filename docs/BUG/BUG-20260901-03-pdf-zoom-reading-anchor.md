# 电子书缩放后返回当前页顶部

- 日期：2026-09-01
- 状态：fixed
- 范围：`PdfReaderView.vue`

## 原因

缩放会重新渲染 PDF。旧页面容器先被清空，滚动区域高度瞬间归零，浏览器将 `scrollTop` 自动收缩为 0；新画布挂载后没有恢复原阅读位置。连续 Ctrl+滚轮时，后续渲染甚至无法再从已清空的页面捕获位置。

## 修复

- 重绘前记录“视口中心位于当前书页高度的相对比例”。
- 新画布挂载后将同一相对位置恢复到视口中心。
- 连续缩放复用待恢复锚点，并用既有渲染 epoch 丢弃过期结果。
- 翻页、目录跳转和回到首页明确关闭位置保持，仍从目标页顶部开始。
- 同页切换批注模式、修改划线或便签引发的重绘也不会跳回顶部。
