# 笔记工作区空白处无法拖动纸张

- 日期：2026-09-01
- 状态：fixed
- 范围：`OpenNotebookEditor.vue`、`notebook-anchor.e2e.cjs`

## 原因

纸张平移手势被硬性限制为 `hand` 工具。即使指针位于纸张外的工作区空白处，普通文字模式也会直接退出，因此用户感觉原有拖动能力失效；同时拖动状态使用普通变量，抓取光标不能可靠响应更新。

## 修复

- 普通模式下，鼠标左键可直接拖动工作区空白处和书脊。
- “移动纸张”工具仍可拖动纸页任意位置。
- 鼠标中键可在任意位置临时拖动，工作区获得焦点后也支持按住空格拖动。
- 正文区域在普通模式继续保留输入和文字选择，不会被左键拖动抢占。
- 拖动状态改为响应式并补充抓手光标、指针取消处理及 Electron UI 回归测试。
