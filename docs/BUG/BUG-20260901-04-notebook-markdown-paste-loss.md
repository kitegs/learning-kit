# 纸质笔记粘贴 Markdown 时公式、列表内容和表格异常

- 日期：2026-09-01
- 状态：fixed
- 范围：`OpenNotebookEditor.vue`、`tests/fixtures/notebook-paste-math.md`

## 原因

纸页的纯文本粘贴转换器逐行创建段落，最初只识别同一行内闭合的 `$...$` 或 `$$...$$`。完整 Markdown 中的跨行公式、标题、强调、引用、列表和表格没有进入统一 Markdown/KaTeX 管线；标准 LaTeX 的 `\[...\]` / `\(...\)` 还会先被 Markdown 当作转义，最终显示为方括号和公式源码。超长的单个有序列表也会退化为按字符切页，可能留下空序号。

## 修复

- 检测到 Markdown 特征时，优先使用剪贴板纯文本并走完整 Markdown + KaTeX 渲染。
- 在 Markdown 解析前保护并渲染 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 四种公式定界符。
- 对剪贴板已经剥掉反斜杠的“单独 `[` + LaTeX 源码 + 单独 `]`”进行保守识别；仅在内容含明确 LaTeX 命令时恢复为块公式。
- 旧笔记加载时修复已经保存的残缺方括号公式，并通过原有自动保存链路写回，避免要求用户重新粘贴。
- 保留普通文本、富 HTML、截图和制表符表格原有粘贴路径。
- KaTeX 公式设为不可直接破坏的内容对象，表格和应用内链接继续补充笔记样式。
- 超长有序列表、无序列表和引用优先按子项分页；有序列表续页保留正确起始编号。
- 增加包含两类跨行公式、三条编号和表格的固定测试样本及 Electron 实际粘贴检查。
