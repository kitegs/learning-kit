# 纸质笔记荧光笔、撤销与批注参数入口失效

- 日期：2026-09-01
- 状态：fixed
- 范围：`OpenNotebookEditor.vue`、`NotesView.vue`

## 现象

1. 荧光笔复用了深色画笔颜色，虽然保存了 alpha，视觉上仍会遮住文字。
2. `Ctrl+Z` 只监听书页容器；从批注弹层选工具后焦点停在工具栏，快捷键无法到达书页。
3. 自动换页会额外写入一次历史快照，用户可能需要撤销两次才看到内容变化。
4. 参数藏在名称不明确的“绘制”弹层中，外层“绘制”功能区没有入口。

## 修复

- 荧光笔改用独立的黄色、宽度和透明度设置，默认透明度 22%，并使用 multiply 混合呈现。
- 在笔记组件根节点捕获 `Ctrl+Z`、`Ctrl+Shift+Z` 和 `Ctrl+Y`；开始绘制时主动聚焦书页。
- 自动分页只更新当前快照，不再创建独立撤销步骤；撤销时保留当前双页位置。
- 顶部与 Word 风格“绘制”功能区均增加明确的“批注参数”入口，右键画笔菜单同步增加入口。
