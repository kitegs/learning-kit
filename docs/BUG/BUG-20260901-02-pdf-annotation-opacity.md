# 电子书手绘荧光笔透明度累积与参数入口缺失

- 日期：2026-09-01
- 状态：fixed
- 范围：`PdfReaderView.vue`

## 现象

电子书“手绘批注”工具栏只有未标注含义的颜色和粗细控件，没有透明度入口。手绘荧光笔虽然设置了 22% alpha，但鼠标每次移动都会把完整路径重新绘制，透明颜色反复叠加后接近不透明。

## 修复

- 实时笔迹改为每次只绘制最新线段，避免 alpha 累积。
- 手绘批注画布使用 multiply 混合，保留 PDF 正文可读性。
- 画笔和荧光笔使用独立的颜色、宽度和浓度，并将参数持久化到本机。
- 工具栏与电子书右键菜单均增加“批注参数”入口；文字选区右键菜单也可打开。
- 批注模式忽略非左键绘制，右键打开参数时不会误留下一笔。
- 新批注把颜色、宽度和透明度写入批注数据；旧批注继续按兼容规则显示。

## 回归检查

集成测试检查右键入口、参数持久化、增量绘制、透明度读取和混合模式。
