---
type: BUG
title: 新笔记撤销可能遗留属性和版本孤儿
created: 2026-10-02
status: fixed
relates: [REQ-20261002-03, BUG-20261002-03]
---

撤销事务复查发现：entity_attributes、note_versions 及无链接的 content_blocks 可以在不修改笔记快照的情况下产生。删除笔记会遗留版本/属性孤儿，自动清理内容块也可能移除用户后来创建的独立数据。

修复策略：新建笔记撤销增加属性和版本检查；任何来源内容块均视为后续资料，保守拒绝撤销，不推断哪些是可删除索引。追加恢复保护内容块引用但不删除版本/属性。补内存 sql.js 回归；引用存在时保留笔记与已执行状态，没有后续资料时正常撤销。
