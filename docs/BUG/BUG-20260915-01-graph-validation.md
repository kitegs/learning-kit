# 问题与修正

- 图谱新建知识点后知识库侧栏计数仍显示旧值：两个视图各自维护列表。KnowledgeView 订阅图谱 store 节点更新，同步计数和列表，保留旧章节/父节点字段。
- 图谱节点生成工具的既有撤销未检查新图谱来源/关系：learning-artifacts 增加引用检查，防止撤销被用户关联后的节点。
- 图谱删除关系确认框采用英文默认按钮：明确中文删除/取消文案，并捕获确认前版本以防并发修改。
- Electron 测试选择了关闭动画中的旧弹窗/旧下拉菜单：按弹窗标题及控件 aria-controls 定位，不再依赖全局可见菜单顺序。
- 重启测试在异步设置加载结束前断言开关：先验证持久化值，再等待恢复条件；不使用固定 sleep 掩盖。
- 一次生产构建在 Vite 输出成功后遇到 Windows libuv `UV_HANDLE_CLOSING` 退出断言。未修改业务代码规避；后续相同构建命令退出 0。若复现需单独排查 Node 运行环境。
